# AGENTS.md — Инструкции для AI-агентов по работе с проектом

## 1. Обзор проекта и архитектура
- Назначение: кастомная интеграция Home Assistant (HACS-совместимая) для сетевого управления аудиоустройствами/усилителями Rotel (протокол IP/TCP, порт по умолчанию 9500).
- Стек: Python 3.11+, Home Assistant Core API (`DataUpdateCoordinator`, Config Flow, push/event-driven TCP-модель).
- Поддерживаемые платформы/домены: `media_player`, `number` (тембры/баланс), `switch` (селекторы акустики A/B, bypass), `select` (диммер дисплея).

## 2. Критически важные правила разработки и ограничения
- Версионирование: при ЛЮБЫХ правках кода обязательно инкрементировать патч-версию (`version`) в `custom_components/rotel/manifest.json` (например, 1.0.5 -> 1.0.6).
- Режим сна (Standby / Auto Power Down):
  * Запрещено отправлять частые keep-alive пинги или периодический поллинг статуса (`power?`, `volume?`), если это сбрасывает встроенный таймер бездействия (APD) усилителя.
  * Интеграция должна опираться на асинхронные push-события от открытого TCP-сокета, а не на агрессивный опрос. Сущности имеют `should_poll = False`.
- Фиксированная громкость (Fixed Volume / Pass-Through):
  * Для входов с фиксированным уровнем звука (например, AUX для AV-ресивера) ползунок громкости в `media_player` должен блокироваться (`available = False` или отключение изменения уровня).
  * При переключении с фиксированного входа на обычный необходимо восстанавливать предыдущий уровень громкости и запрашивать актуальный статус устройства.
- Оптимистичные обновления и мерцание (Flickering):
  * Не вызывать `async_write_ha_state()` без реального изменения данных.
  * Использовать дебаунс/троттлинг при обработке потока TCP-пакетов.

## 3. Структура репозитория
- `custom_components/rotel/`:
  * `manifest.json`: манифест интеграции, зависимости, версия.
  * `config_flow.py`: UI-мастер настройки и валидация подключения.
  * `coordinator.py`: сетевой клиент TCP, координатор данных и диспетчер событий.
  * `media_player.py`: базовое управление питанием, громкостью (шкала 0-96) и источниками.
  * `number.py`, `switch.py`, `select.py`: расширенные настройки звука и устройства.
  * `const.py`: константы протокола, команды и списки входов.

## 4. Чек-лист перед завершением задачи (Definition of Done)
1. Код полностью асинхронный (`asyncio`).
2. Соблюдены правила типизации (Type hints).
3. Версия в `manifest.json` поднята на один патч.
4. Логика не блокирует переход устройства в Standby.
